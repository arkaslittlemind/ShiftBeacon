# ShiftBeacon (WIP)

A location-aware shift management application for healthcare teams. Care
workers clock in and out of shifts from within a manager-configured workplace
perimeter (geofence); managers get visibility into current staff presence,
shift history, and attendance analytics.

See `blueprint/context/project-overview.md` for the full project overview
(generate it with `/overview`), and `project requirement docs/` for the
original source plans.

## Commands

- Dev server: `npm run dev` (http://localhost:3000)
- Build: `npm run build`
- Production server: `npm run start`
- Lint: `npm run lint`
