# Feature: Pikaicons migration

**From build-plan:** feature 21b (proposed)
**Status:** not started

## Goal

Make Pikaicons the only icon source, as `AGENTS.md` now requires, by replacing
every `lucide-react` import and removing the dependency.

## In scope

- Replace the 21 Lucide icons used across 16 files with Pikaicons components
  generated by `npx pikaicons add <name...>` (stroke variant by default).
- Remove `lucide-react` from `package.json`.
- Keep each icon's size, colour, `aria-hidden`, and accessible-label behaviour.

## Out of scope

- Adding new icons that later screens need (each screen spec adds its own).
- Visual restyling around the icons.

## Build steps

- [ ] **Step 1 - Generate components** - run `npx pikaicons add` for every
  icon in the mapping and commit what it writes, using the import line it
  prints. *Done when:* the generated components type-check and render one icon
  on a scratch import.
- [ ] **Step 2 - Shell and shared** - swap icons in `components/shell/*`,
  `components/shared/*`, `components/ui/dropdown-menu.tsx`,
  `components/ui/sheet.tsx`. *Done when:* the mobile nav opens and closes with
  the new menu and close icons, and the empty and forbidden states render.
- [ ] **Step 3 - Feature screens** - swap icons in `components/manager/*`,
  `components/worker/*`, `components/marketing/*`, and the `app/*` pages
  (`error`, `not-found`, `offline`, manager dashboard). *Done when:*
  `grep -r "lucide-react" app components` returns nothing.
- [ ] **Step 4 - Spinner + dependency** - add the CSS ring spinner used where
  `Loader2` was, then `npm uninstall lucide-react`. *Done when:* the ask card
  loading state shows the ring spinner, `npm run build` passes, and
  `lucide-react` is absent from `package.json` and the lockfile.

## Data / contracts

None. If `empty-state.tsx` takes an icon component as a prop, keep the prop's
type compatible (a React component accepting `className`).

## Testing

- No logic. `components/shared/empty-state.test.tsx` imports a Lucide icon;
  update it to a Pikaicons component. The full suite must stay green.
- Evidence: a screenshot of each surface that had an icon.

## Notes for the AI

- Never hand-draw an SVG or add another icon library (`AGENTS.md`, Icons).
- Never ask the user for a Pikaicons key. If a locked icon seems necessary, use
  the free fallback and mention the license option.
- Decorative icons keep `aria-hidden="true"`; icon-only buttons keep their
  `aria-label`.
